# ویجت PriceYar — ساخت با GitHub Actions

این پروژه نسخه HTML فعلی PriceYar را داخل WebView اجرا می‌کند و اطلاعات را علاوه بر localStorage در SharedPreferences اندروید نگه می‌دارد تا ویجت هم بتواند همان اطلاعات را بخواند.

## بدون Android Studio و بدون AIDE
1. کل پوشه پروژه را در یک Repository جدید GitHub آپلود کن.
2. وارد تب **Actions** شو.
3. Workflow با نام **Build PriceYar APK** را انتخاب کن و **Run workflow** بزن.
4. بعد از پایان Build، در صفحه همان اجرا، بخش **Artifacts** را باز کن و `PriceYar-debug-apk` را بگیر.
5. APK را روی گوشی نصب کن.
6. برنامه را یک بار باز کن، کالاها را وارد کن، سپس از صفحه اصلی گوشی ویجت **مدیریت قیمت فروشگاه / جستجوی سریع کالا و قیمت** را اضافه کن.

## نکته مهم درباره جستجو
ویجت‌های استاندارد اندروید اجازه قرار دادن یک EditText واقعی داخل RemoteViews را به شکل عادی نمی‌دهند. بنابراین ظاهر ویجت خودش نوار جستجوی مینیمال است؛ با لمس آن صفحه جستجو باز می‌شود، نام کالا را می‌نویسی و نتیجه/قیمت روی ویجت نمایش داده می‌شود.

## تغییر اندازه
ویجت قابل تغییر اندازه افقی و عمودی است و اندازه نوشته‌ها با اندازه ویجت تا حدی متناسب می‌شود.

## شفافیت و قفل صفحه
پس‌زمینه ویجت کاملاً شفاف است و فقط خط ظریف نوار جستجو و آیکون سفید دیده می‌شود. پشتیبانی از lock screen با `keyguard` اعلام شده، اما نمایش واقعی روی صفحه قفل به نسخه اندروید و لانچر گوشی بستگی دارد.

## نسخه شاگرد
دکمه «نسخه برای شاگرد» همچنان فایل HTML مستقل می‌سازد. اگر شاگرد هم **ویجت اندرویدی** می‌خواهد، باید نسخه APK همین پروژه را روی گوشی خودش داشته باشد؛ فایل HTML به تنهایی ویجت native اندروید ایجاد نمی‌کند.
